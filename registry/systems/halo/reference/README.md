# halo — reference

Design values only. No product's marks, wording or screen layouts are reproduced.

- **The halo HUD itself (2026-09-25).** An agent interface whose windows float over a live wave on the web and
  over the user's desktop on macOS. Taken from it: the night-navy ground, the smoked-glass windows (78% fill,
  28px blur, 1.5 saturation, a long soft shadow and a 7% white top edge), 20px window corners, 14px window
  margins, the sky-blue signal and the violet · amber · emerald · rose collection hues.
- **A research canvas screenshot the owner shared (2026-09-25)** for the card anatomy: media first and edge to
  edge, a bold title, one quiet meta line (source · count · when), and a small tab floating above the card for
  its label and actions. Only that anatomy was taken; its colours, type and layout were not.
