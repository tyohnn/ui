# multi-system

One monorepo, two design systems, one per app. **Generated by `tooling/scaffold-prototype`** (the prototype of
the tyohnn CLI); do not edit the generated files by hand, change the prototype or the registry and regenerate.

This folder is its own npm workspaces + Turborepo repository. It is not part of tyohnn's root workspaces.

| App | Port | System | Icons | Fonts | Default mode |
|---|---|---|---|---|---|
| `apps/crm` (Next 16) | 3201 | graphite | lucide | Pretendard | dark |
| `apps/admin` (Next 16) | 3202 | foundation | hugeicons | Inter, Pretendard for Hangul | light |

`foundation` is a **test stand-in**: the CLI will not list it (it is the maintainer master copy). It is here
because it differs from graphite in every layer and icon library; replace it with `vega` once that system exists.

```
packages/ui/                    @acme/ui
  src/components hooks lib      registry/ui, aliases rewritten to @acme/ui/...
  src/icons/libraries/          lucide.tsx · hugeicons.tsx (only the libraries in use)
  src/icons/index.ts            re-exports lucide, the monorepo default (packages/ui's own tsc)
  src/systems/graphite/         registry/systems/graphite/styles + DESIGN.md + system.json
  src/systems/foundation/       registry/foundation/styles + DESIGN.template.md + system.json
apps/crm · apps/admin           each imports exactly one system in src/app/globals.css
tyohnn.json                     source commit · per-app system, icons, fonts, mode · hashes of copied files
```

## Regenerate

From the tyohnn repository root:

```sh
rm -rf examples/multi-system/{apps,packages,tyohnn.json,package.json,turbo.json,tsconfig.base.json,.gitignore}
node tooling/scaffold-prototype init --target examples/multi-system --ui packages/ui --scope @acme \
  --system graphite --app apps/crm --icons lucide --font pretendard --port 3201
node tooling/scaffold-prototype add-system --target examples/multi-system \
  --system foundation --app apps/admin --icons hugeicons --font inter --port 3202
```

## Run and check

```sh
cd examples/multi-system
npm install
npx turbo typecheck build
npm run dev -w @acme/crm      # http://localhost:3201
npm run dev -w @acme/admin    # http://localhost:3202
node ../../tooling/scaffold-prototype doctor --target . --built
```

Compare against the preview started for the same system (from the tyohnn root; one preview at a time, they
share Vite's dependency cache):

```sh
SYSTEM=graphite node apps/preview/scripts/vite-system.mjs --port 5175 --strictPort --force
node tooling/snapshot/compare-computed.mjs --a http://localhost:3201/ --system graphite --mode dark --preview http://localhost:5175 --icons
SYSTEM=foundation node apps/preview/scripts/vite-system.mjs --port 5176 --strictPort --force
node tooling/snapshot/compare-computed.mjs --a http://localhost:3202/ --system foundation --mode dark --mode-a dark --preview http://localhost:5176 --icons
node tooling/snapshot/compare-computed.mjs --a http://localhost:3202/ --system foundation --mode light --preview http://localhost:5176 --icons
```
