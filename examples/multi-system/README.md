# multi-system

One monorepo, two design systems, one per app. **Generated by the tyohnn CLI** (`packages/cli`); do not edit the
generated files by hand: change the registry or the CLI and regenerate.

This folder is its own npm workspaces + Turborepo repository (started from `packages/cli/fixtures/turborepo`). It is
not part of tyohnn's root workspaces.

| App | Port | System | Icons | Fonts | Default mode |
|---|---|---|---|---|---|
| `apps/crm` (Next 16) | 3145 | graphite | lucide | Pretendard | dark |
| `apps/admin` (Next 16) | 3146 | mira | hugeicons | Inter, Pretendard for Hangul | light |

The two apps deliberately use different icon libraries, to show per-app icon resolution; one library per monorepo is
the simpler choice.

```
packages/ui/                    @acme/ui (created by init)
  src/components hooks lib      registry/ui, aliases rewritten to @acme/ui/...
  src/icons/libraries/          hugeicons.tsx · lucide.tsx (only the libraries in use)
  src/icons/index.ts            re-exports the default library (packages/ui's own typecheck)
  src/systems/graphite/         registry/systems/graphite (styles · DESIGN.md · system.json)
  src/systems/mira/             registry/systems/mira
apps/crm · apps/admin           globals.css imports one system; tsconfig paths point @acme/ui/icons at the app's library
apps/*/src/app/tyohnn/component-sheet/   the preview's component sheet (--example component-sheet)
tyohnn.json                     source commit · per-app system, icons, fonts, mode · added packages · copied-file hashes
```

## Regenerate

From the tyohnn repository root:

```sh
npm run build -w tyohnn
git archive --format=tar.gz --prefix=tyohnn-main/ HEAD > /tmp/tyohnn.tar.gz
cd examples/multi-system
rm -rf apps packages node_modules tyohnn.json package.json package-lock.json turbo.json .gitignore
cp -R ../../packages/cli/fixtures/turborepo/. . && rm packages/.gitkeep
sed -i '' 's/"turborepo-fixture"/"multi-system"/' package.json
sed -i '' 's/-p 3143/-p 3145/g' apps/crm/package.json && sed -i '' 's/-p 3144/-p 3146/g' apps/admin/package.json
node ../../packages/cli/dist/index.js init --system graphite --app apps/crm --scope @acme --example component-sheet --yes --source /tmp/tyohnn.tar.gz
node ../../packages/cli/dist/index.js add mira --app apps/admin --example component-sheet --yes --source /tmp/tyohnn.tar.gz
```

(`--source` reads this checkout's committed registry through the same extraction as a GitHub download; without it
the CLI downloads `tyohnn/ui@main`.)

## Run and check

```sh
cd examples/multi-system
npx turbo run build typecheck
node ../../packages/cli/dist/index.js doctor --built
npm run start -w apps/crm      # http://localhost:3145/tyohnn/component-sheet
npm run start -w apps/admin    # http://localhost:3146/tyohnn/component-sheet
```

Compare against the preview started for the same system (from the tyohnn root; one preview at a time, they share
Vite's dependency cache):

```sh
(cd apps/preview && SYSTEM=graphite node scripts/vite-system.mjs --port 5201 --strictPort --force)
node tooling/snapshot/compare-computed.mjs --a http://localhost:3145/tyohnn/component-sheet --system graphite --mode dark --mode-a dark --preview http://localhost:5201 --icons
(cd apps/preview && SYSTEM=mira node scripts/vite-system.mjs --port 5201 --strictPort --force)
node tooling/snapshot/compare-computed.mjs --a http://localhost:3146/tyohnn/component-sheet --system mira --mode light --mode-a light --preview http://localhost:5201 --icons
```
