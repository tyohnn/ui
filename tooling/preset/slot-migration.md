## Procedure, per system

1. `node tooling/snapshot/compare-computed.mjs --dump before-<system>-<mode>.json --system <system> --mode <mode>`
   for **both** modes first. Nothing below may change a computed value.
2. For each file in the tables below: replace the system's rule with **foundation's current rule**
   (`registry/foundation/styles/components/<file>`), then set the listed slots to the listed values in the
   system's `styles/tokens.css` / `styles/globals.css` — in place, in the axis block the name belongs to,
   not in the backfill block at the end of the file. Delete the backfilled default once you have written
   the real value, and delete the backfill marker comment when its block is empty.
3. Rename the system-only tokens listed under "Renames" and update their readers; apply "Drop" and "Already a slot".
4. `node tooling/build-system <system>` · `node tooling/scan-tokens <system>` · `node tooling/validate-system <system>`.
5. Dump both modes again and `--diff` against step 1: **0 differences**. Then re-run the reference
   comparison (`compare-shadcn.mjs --system <system> --mode light|dark`) and confirm the counts in
   `reference/README.md` are unchanged. graphite has no reference app (it is a screenshot system), so the
   dump diff is its whole check.

## How to read the tables

Each row is one declaration where foundation now reads a v4 slot and the system writes something else.
The **rule** column is the nested selector chain in the system's copy of that file (`>>` = nesting), so
`.cn-badge >> & > svg` is the `& > svg` block inside `.cn-badge`.

Rows where the system's value already equals foundation's default are **not listed** — adopting
foundation's rule handles them with no token to write. Their count is given per system so the scale of
the file swap is visible.

⚠ The tables are generated by matching the same selector chain and property on both sides. Where a system
**restructured** a rule (a different selector, a dropped box, an added declaration — DESIGN.md §5 lists the
four shapes) there is no match to report, and the system's `reference/README.md` already names those rules
under its layer-3 notes. Read both.
